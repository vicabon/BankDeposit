## 目的

本技能專門用於研究、整理、比較與追蹤台灣主要數位銀行及純網路銀行之最新新台幣高利、優利定存方案。

主要研究銀行包括：

1. LINE Bank
2. 樂天國際銀行
3. 將來銀行
4. 王道銀行
5. 匯豐銀行

本技能的核心目標，是找出「**今日開始仍可承作、一般既有客戶也可參加、尚未結束、尚未取消且尚未額滿**」的高利／優利定存方案，並以官方銀行資料進行交叉驗證。

---

# 二、研究時間基準

## 1. 「今日可承作」定義

每次執行研究時，以**執行當日台灣時間（Asia/Taipei）**為基準。

只顯示在當日仍符合承作條件的方案。

例如：

- 活動開始日 ≤ 今日 ≤ 活動結束日 → 可納入
- 活動尚未開始 → 不納入
- 活動已結束 → 不納入
- 官方公告已取消 → 不納入
- 官方公告顯示額度已滿 → 不納入

如果官方網站沒有明確標示活動期間，應依官方頁面目前狀態判斷；無法確認時必須標示「官方資料未明確載明」。

# 五、方案篩選規則

## 1. 排除「僅新客戶」方案

如果方案明確要求：

- 僅限新戶
- 僅限新客戶
- 首次開戶
- 新開戶限定
- 新戶限定
- 新會員限定
- 新申請客戶限定

則：

**完全排除，不顯示於最終結果。**

---

## 2. 排除「僅新開戶」方案

如果必須：

- 新開立銀行帳戶
- 新開立存款帳戶
- 新申請特定帳戶
- 新戶才能參加

則排除。

---

## 3. 一般既有客戶可參加

優先保留：

- 既有客戶可參加
- 既有存戶可參加
- 不限制新舊戶
- 一般符合資格之客戶均可參加

若官方沒有明確說明是否限新戶：

- 不可自行推論
- 必須標示「官方資格未明確載明」
- 若無法確認是否符合本 Skill 的既有客戶條件，原則上不納入主要比較表

若官方頁面明確顯示：

- 活動進行中
- 尚可申請
- 尚可承作

# 九、利率比較規則

不得只比較「最高年利率」。

應同時考慮：

1. 年利率
2. 定存天期
3. 優惠利率適用金額
4. 最低承作金額
5. 最高優惠額度
6. 實際活動期間
7. 是否所有客戶皆可參加
8. 領息方式
9. 是否有其他附加條件

如果不同銀行天期不同：

不得直接宣稱某方案「一定比較好」。

應呈現：

> 利率／天期／額度／條件的客觀差異。

---

# 十、同銀行多方案處理

同一家銀行如果同時存在多個符合資格的方案：

全部列出。

例如：

LINE Bank：

- 新台幣 1個月
- 新台幣 3個月
- 新台幣 6個月

不可只挑最高利率的一個方案。

---

# 十一、「新資金」條件

「新資金」與「新客戶」不同。

如果方案要求：

- 新資金
- 指定期間新增資金
- 外部匯入資金
- 活動期間新增存款

但並未限制新戶：

可以納入。

必須明確標示：

> 承作條件：需符合新資金條件

不得將「新資金」誤判為「新客戶」。

---

# 十三、額度限制

如果優惠利率只適用於特定金額，例如：

> 最高優惠額度 NT$100萬元

必須明確列出。

若超過優惠額度後：

- 超額部分適用一般利率
- 超額部分不計息
- 超額部分適用其他利率

必須依官方規則分開說明。
